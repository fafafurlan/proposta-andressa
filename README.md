# Proposta de social media · estúdio de sobrancelhas

Página de apresentação que montei para propor a gestão do Instagram de um estúdio de design de sobrancelhas. Em vez de só explicar o serviço, a proposta já mostra o trabalho pronto.

## O que a proposta mostra

- **Leitura do perfil atual:** pontos fortes e oportunidades.
- **Identidade visual** pensada para o estúdio: delicada e elegante.
- **Simulação do feed** com os novos posts, num celular na própria página.
- **4 carrosséis prontos** (em `midia/`): primeira vez no design, formato do rosto, lápis, gel e sombra, e campanha de dezembro.
- **2 Reels** com capa.
- **Plano de publicação:** três posts por semana, com divulgação do método e do novo serviço.
- **Versão em PDF** para enviar pelo WhatsApp (`Portfolio-Andressa.pdf`).

## Como ver

Abra o `index.html` no navegador. Não precisa instalar nada.

## Ferramentas

HTML · CSS · JavaScript · direção de arte · roteiro e edição de Reels
